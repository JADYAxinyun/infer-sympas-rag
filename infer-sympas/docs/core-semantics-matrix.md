# SymPas 核心语义逐项对照

核对依据：用户提供的 Zhang, *SymPas: Symbolic Program Slicing*, JCST 36(2),
397–418 (2021) 原文，期刊 pp.401–407（PDF 5–11）。原始 PDF 只读。
本表描述 Infer SIL 适配，不将 SIL 指令号等同于论文 LLVM 指令号。

分类：**验证子集一致**仅指列明测试中的语义一致；**保守近似**表示可能多保留；
**未实现**表示没有对应完整机制；**无法验证**表示没有足以支持等价性或评测结论的证据。

| 原文要求 | 当前实现与证据 | 分类及边界 |
|---|---|---|
| 式(1)，指令自身 + 引用值 + 控制来源 | SymPasSymbolic 的 Source、eval、idt 与控制位置；symbolic_control、reference 分支/循环、跨三层控制回归 | 验证子集一致；控制依赖为后支配/谓词的保守适配，未证明对所有 SIL CFG 等价 |
| 式(2)，单值替换、多值/汇合合并 | 临时值与本地单目标强更新；可能别名/聚合/堆弱更新；CFG 状态 join | 标量赋值覆盖参考一致；内存更新保守，不能称完整 LLVM phi/select 模型 |
| 式(3)，形参/全局符号初值 | Formal、Global、Pointee token，作用域内存键和调用点替换 | 验证子集一致；Pointee 是本适配的显式内存扩展 |
| 式(4)，退出命名值符号表 | return、outputs、instruction_slices、variable_slices，包含局部/全局程序点状态 | 基础出口/查询子集一致；未实现论文所有 LLVM 命名值的原样 T_P 表 |
| 式(6)–(8)，OUT 与参数摘要 | modified 位置集合生成逐输出 dependencies/aliases；paper_output_parameters、heap_bind 等 | 验证子集一致；不是按 T_P(x) 与初值精确比较来划分完整 IN/OUT，可能多保留 |
| 式(9)–(11)，SPEC 与输出写回 | 从调用前快照实例化 formal/pointee/global/heap，写回实际目标，保留被调用者 Source | 换序、多调用点、嵌套、多层调用子集一致；堆站点/未知调用可能合并额外依赖 |
| §3.3，同步递归固定点 | 有限符号与分配点域；SCC 从空摘要同步迭代直到整分量相等；顺序反转与跨文件缓存失效测试 | 已验证 5 个 SCC 收敛；未实现全量间接调用图解析、SCC 并行性能等价 |
| p.405，数组/结构整体与别名辅助 | 字段/数组整体折叠；局部 points-to，形参 may-alias，分配点 Heap，指针返回/输出别名 | 保守近似；没有执行论文 LLVM basicaa/gvn，不承诺其别名精度 |
| p.401，终点单变量准则 | return_value 与出口变量依赖 | 构造参考样例一致；多返回按静态路径合并 |
| 任意位置与六类准则（项目扩展） | query_slice.py 仅选择真实 Checker 证据；变量按 after_instruction 快照；六类集成测试 | 已验证子集；同一源码行可对应多个结果；不支持任意表达式/执行前状态 |
| 第4节前向切片 | 当前做反向依赖闭包，前向遍历仅是计算手段 | 未实现独立的论文前向切片查询；不在本轮六类反向准则内 |
| 论文正确性/性能实验 | 9 个预先推导参考及规则回归，记录 missing/extra、Precision/Recall/F1、大小、时间、字节数 | 无法验证论文全量等价、通用 soundness、论文性能倍率或数据集结果 |

## 内存与失败边界

- 分配点弱更新覆盖同站点多次动态分配，工厂重复调用可相互别名；不同直接分配点
  的隔离有参考回归。释放、分配失败、未定义行为不由此切片器验证安全性。
- 未知地址读取包含所有已追踪位置；未知写入弱更新已追踪内存并保留别名。
  未追踪外部状态、逃逸栈地址、复杂指针算术、并发与异常控制不保证精确覆盖。
- 未解析调用保守保留实参与可读写指针内存，不能据此声明所有外部全局副作用 sound。
- 非法 C、缺失 Infer、损坏输出、缺失切片和不匹配准则有失败/不支持反馈；
  参考评测拒绝空清单和不支持的准则，不用空结果生成成功指标。

参考来源为 AI 对源码的预先推导，未经独立人工审核。当前只有规则化回归测试，
尚未完成基于人工参考切片的完整精度评估。已通过的构造样例不能替代此缺失证据。
