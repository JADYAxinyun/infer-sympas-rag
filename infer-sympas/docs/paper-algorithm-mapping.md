# SymPas 论文到 Infer 的算法映射

依据：Ying-Zhou Zhang, *SymPas: Symbolic Program Slicing*, JCST 36(2),
397–418 (2021), DOI 10.1007/s11390-020-9754-4。以用户提供的 22 页 PDF
为原文；下列页码为期刊页码，括号内为 PDF 页码。

本页保留早期差距与实现进展的历史顺序，不作为当前状态总表。摘要版本 9 的
逐项现状、证据和残余差异见 [当前语义对照](core-semantics-matrix.md)。

## 核心语义与实现要求

| 原文 | 语义 | Infer 实现要求 | 当前差距 |
|---|---|---|---|
| §2.2, 式(1), p.401 (5) | `L(i)` 合并自身、控制依赖、引用值切片 | 用稳定的 SIL 指令身份表示依赖集合；控制来源包含位置 | 目前以位置和反向 frontier 表示，尚无完整 IDT |
| 式(2) | `S(x)` 为值的切片；单值定义替换，多值定义合并 | SSA 临时变量与可修改内存分开；CFG join 合并状态 | 目前未保存全部值的符号切片表 |
| 式(3) | 形参、全局初值为符号占位符 | 作用域限定的 formal/global token | 已有 formal/global 返回依赖，但非完整符号表 |
| 式(4), p.402 (6) | `T_P` 保存退出处命名值的符号切片 | 按输出分别保存依赖和过程内语句 | 目前只保存返回值形参/全局依赖 |
| 式(6)–(8), p.406 (10) | 用 `T_P` 识别 IN/OUT 及每个输出的 SUMM | 支持返回值、被修改的指针形参和全局变量 | 输出参数及全局写入摘要未完成 |
| 式(9)–(11), pp.406–407 (10–11) | 每个调用点用 SPEC 替换符号参数，再传播输出 | 实参替换必须局限当前调用点，写回相应实际内存 | 目前主要实例化返回值依赖 |
| Algorithm 2, §3.3, p.407 (11) | 叶过程优先；递归 SCC 迭代到固定点 | 有限依赖域、明确 SCC 收敛；缓存与失效验证 | 有 Infer 调度及递归 smoke，不能据此宣称论文固定点复现 |

这是算法复现的差距清单；增加 JSON 输出不会使上述算法项自动完成。

## 优先验收样例

1. Fig.1 (p.398 / PDF 2)：同一个 `Id` 的两个调用，不应混合两个实参。
2. Fig.4–5、Table 1 (pp.403–404 / PDF 7–8)：`add(a,b)` 修改 `*a`，
   其输出应依赖输入 `*a` 与 `*b`；`b` 的输出保持输入值。
3. §3.3 (p.407 / PDF 11)：`add → inc → A → main`，验证无返回值的
   调用也能传播被修改的指针实参；通过 `return sum` 包装选择可自动断言的准则。
4. 递归和互递归：验证摘要固定点以及终止，而非只检查进程没有挂起。

每项需记录源码、准则、预期数据/控制/摘要、实际输出及断言。论文样例
适配到 SIL 后的源码行号不能直接作为 LLVM 指令号使用。

## 复现范围

论文 §2.2 的基础准则是程序终点的单变量，§7 (p.416 / PDF 20)
也明确列为限制。用户要求的位置、调用点和 finding 准则属于本项目扩展，
应独立验收，不能描述成论文原有的全部功能。

论文 p.405 (PDF 9) 使用 LLVM 的 basicaa/gvn，并把数组和结构体成员
作为整体处理；在 SIL 中仍须提供真实的别名近似，不能假设这些 LLVM pass
已被 Infer 执行。精细字段敏感性是可选改进，不能替代输出参数传播。

当前只有规则化回归测试，尚未完成基于人工参考切片的完整精度评估。
论文中速度、内存与规模结论不能作为本实现的测量结果。

该实现尚未保存论文完整的指令表 `L(i)`，控制传播使用保守近似；这不是

### 后续实现与实测

摘要增加带过程身份的 SIL 语句 token，按指令保存依赖快照；符号替换保留
被调用者的语句来源。结构化报告导出 `instruction_slices`、返回依赖来源、
输出内存来源、控制位置和静态调用依赖边。该表是 SIL 上的适配，仍需验证
完整的论文控制/内存语义，不能声称论文等价性已获证明。

`query_slice.py` 从 Checker 已计算的快照查询返回值、变量定义、调用点、
finding 变量定义、返回点、文件行列。Python 仅选择和组织证据，不解析 C AST
或重新推断切片。位置可能对应多条 SIL 指令，行列查询返回所有匹配结果；
变量查询目前定位定义点，不支持任意使用位置上的完整变量状态。

已实测 28 条摘要断言（含无关分支排除）、8 条真实 Infer 准则测试。
`test_summary_cache.py` 在同一 Infer 数据库执行冷分析、无改动增量分析，
随后以 `capture --continue` 重新捕获修改后的被调用者，并以
`analyze --incremental-analysis --changed-files-index` 验证调用者摘要更新。
此测试验证持久化结果一致性及失效传播，尚不测量缓存命中率。

`infer_adapter.py` 保留原始结构化证据；对缺少结构化结果的旧 Checker 标记
`unsupported`，对损坏 JSON 标记 `failed`。5 条适配器相关测试通过。
上述变更尚未同步 GitHub。
