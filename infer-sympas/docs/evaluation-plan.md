# 评测计划

当前测试确认分析器能够运行并覆盖主要依赖类型，但测试数量不等于准确率。下一阶段按以下顺序评测：

1. **回归正确性**：每个测试保留人工期望的变量、位置和路径条件。
2. **覆盖率统计**：记录函数、调用点、字段、数组、指针和分支场景数量。
3. **人工真值**：为每个函数标注应进入切片的语句集合。
4. **指标计算**：
   - Precision = 正确进入切片的语句 / 分析器输出语句
   - Recall = 正确进入切片的语句 / 人工真值语句
   - F1 = Precision 与 Recall 的调和平均
5. **性能记录**：记录 capture、analyze 的耗时、结果数据库大小和峰值内存。
6. **对比实验**：比较无控制依赖、保守控制依赖和精确控制依赖三种配置。

`tools/summarize_suite.py` 只统计报告规模，不会把 issue 数量误当成 Precision 或 Recall。正式论文结论必须基于人工真值和可复现的运行记录。
