# SymPas 复现状态

当前核心实现为摘要版本 9；阶段进展见 [核心复现计划](core-reproduction-plan.md)，
当前验收依据见 [核心审计](core-reproduction-audit.md) 与
[逐项语义对照](core-semantics-matrix.md)。旧阶段报告的数字是历史记录。

当前是可运行、可测试的 Infer SIL/CFG SymPas 风格分析器，尚不能称为
LLVM-SymPas 的完整复现。以 [验收证据与边界](acceptance-evidence.md) 为当前清单，
以 [论文算法映射](paper-algorithm-mapping.md) 为设计依据。

## 已实现并有回归

前向符号输入依赖、返回值/输出参数/全局写入摘要、调用点替换、多层传播、
指针返回别名、SIL 指令依赖快照、控制位置和六类准则查询。真实 Infer 集成
覆盖准则匹配、失败反馈及同一数据库内的摘要更新。旧反向报告保持兼容。

## 部分完成

控制依赖、别名和聚合内存采用保守近似；变量位置准则定位 SIL 指令后状态，
未指定位置时仍选择定义快照；
finding 变量需要外部提供位置和变量；调用链输出为静态依赖边。
递归/互递归已使用显式同步 SCC 摘要迭代，并有轮数、定义顺序不变性及跨文件
失效测试；尚未证明与论文完整 LLVM 语义的精度等价。

## 未完成

已支持基本堆分配点、返回堆指针与输出别名、未知地址的已追踪内存保守读取。
仍未完成复杂对象敏感堆分析、全量间接调用目标解析、任意表达式/执行前状态准则、
论文全量数据集及 SDG-IFDS 对照、独立人工参考切片和论文性能倍率复现。
